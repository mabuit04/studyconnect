# Ranking of important UX Factors of Studyconnect

## 1 Pragmatic Quality
  The product is practical and functional overall.
  ### Reason: 
    It should help students to organize their studys. If it is not helpful because there are software bugs, students will not use it.
  ### Supporting Design/Factor:
  Only implement features when they are completely tested and work as expected. Do not release an unfinished product (banana software). Do quality checks before each release, use a small group of beta testers to identify problems. In general: small steps make the product complete, don't implement too many functions at once.
  ### Risks if UX Factor is Ignored:
  App won't be downloaded or used -> all our work for nothing. Or the app is only used for a small time and the users soon deinstall the app because it does not work right.
  
## 2 Appearance
  The product is attractive, beautiful and/or designed in an appealing way.  
  ### Reason: 
    Because it encourages the students to use the app on a daily basis. Maybe it becomes a hype to use this app, because it is so fancy.
  ### Supporting Design/Factor:
  Modern design, cool effects when changing pages/submenus of the app. Neatless design that blends in the operating system (Android, IOS..)
  ### Risks if UX Factor is Ignored:
  App looks like from 2010, is boring and is only used if the features are important enough for the users to deal with the interface.
  
## 3 Controllability
  The product always responds to user interaction in a predictable and consistent way.
  ### Reason: 
    A product that does not behave the way it should, is hard to use to achieve goals. This is also important for students to track their tasks and not to miss any assignments. 
  ### Supporting Design/Factor:
  Every submenu should have the same buttons (OK, Cancel...) and the underlying action should always be the same. The interaction with the user should be clear, for example with direct questions: "Do you really want to delete this appointment?" -> Choices are "Yes" and "No"
  ### Risks if UX Factor is Ignored:
  If the interaction is more like a lottery game, the user will soon be disappointed and stop using the app.
  
## 4 Social Influences
  Interacting with the product helps the user to socialize or present themselves in a favorable way.
  ### Reason:
    To connect with other students is an mandatory functional requirement. Studys are way easier when other students can help you with tasks
  ### Supporting Design/Factor:
  To invite other students and to form teams is mandatory to achieve the social factor of the app.
  ### Risks if UX Factor is Ignored:
  Without the social influence the app will only be used by single students and there are no real reasons to invite other fellow students to the app.

## 5 Ease of Use
  The product is easy to operate.
  ### Reason:
    To be able to use the product on a daily basis it should be easy to operate. An easy to use product increases the overall efficiency
    when using it.
  ### Supporting Design/Factor:
The app should scale correctly depending on what device it is used. On small mobile displays is readability extremely important. More important than fancy effects or moving backgrounds for example. On a big 4k-Display the mobile design may look bizarre, because there is so many free space. So the design has to adapt to the hardware automatically.
  ### Risks if UX Factor is Ignored:
The app is looking perfect on a small screen and bad on a big screen or it does never look good at all because it is not designed for one or the other.
